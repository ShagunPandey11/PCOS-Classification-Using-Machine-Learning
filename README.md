PCOS Classification Using Machine Learning

Project Overview

Polycystic Ovary Syndrome (PCOS) is a common hormonal disorder affecting women of reproductive age. This project is an academic machine learning exercise and explores the use of machine learning classification algorithms to identify patterns in patient data and predict the presence of PCOS.

The project implements and compares three classification algorithms: Logistic Regression, K-Nearest Neighbors (KNN), and Gaussian Naive Bayes.
The dataset contains patient-related attributes used as input features for classification.
Number of records: 538, Original columns: 42, Input features used: 40, Target variable: PCOS (Yes/No).

Technologies Used are Python, NumPy, Pandas, and Scikit-learn.

Results show that Logistic Regression has the highest accuracy at 86.42%, followed by KNN and then Gaussian Naive Bayes with 85.19% and 83.95% accuracy, respectively.
